# ⚖️ Justice Hub – Frontend

## 🚀 Overview

**Justice Hub** is a full-featured legal services platform that connects users with verified lawyers and chartered accountants. It provides a seamless experience for discovering professionals, booking consultations, managing cases, and communicating in real-time — all through a modern, responsive interface.

The frontend is designed with scalability, clean architecture principles, and user experience in mind, supporting three major roles:

* 👤 **Client**
* ⚖️ **Lawyer**
* 🛠 **Admin**

🔗 **Live Demo:** [*[Live Link]*](https://justiceui2.vercel.app/)

## ⚙️ Setup Instructions

```bash
# Clone the repository
git clone https://github.com/Ansar1503/Justice-Hub-UI.git

# Navigate into the project
cd Justice-Hub-UI

# Install dependencies
npm install

# Start development server
npm run dev
```
